# 지구촌 전통의상 포토부스

만 5세 유아를 위한 태블릿 가로 화면 포토부스입니다. 8개 전신 캐릭터 중 하나를 고르고, 전면 카메라로 얼굴을 찍어 캐릭터의 투명한 얼굴 자리에 합성한 뒤 PNG로 저장합니다. 사진은 브라우저 메모리에서만 처리하며 서버에 보내거나 자동 저장하지 않습니다.

## 실행과 배포

- Windows PC 로컬 확인: `start-photobooth.cmd`를 두 번 눌러 실행하고 열린 창을 유지합니다. `http://localhost:4173`이 브라우저에 열립니다.
- 수동 실행: 이 폴더에서 `python -m http.server 4173 --bind 127.0.0.1`을 실행한 뒤 `http://localhost:4173` 접속
- 수업용: `dist` 폴더를 정적 웹 호스팅에 올리고 HTTPS 주소로 접속
- 태블릿 11대 각각에서 Chrome 기반 브라우저로 접속하고 카메라 권한을 허용
- 태블릿에서 저장 버튼을 누른 후 다운로드 또는 파일 앱에서 PNG 확인

`index.html`을 직접 두 번 눌러 `file://` 주소로 열면 브라우저가 의상 PNG의 픽셀 읽기를 막아 합성이 비어 보일 수 있습니다. PC에서는 위 실행 파일로 `localhost`를 사용하고, 태블릿에서는 HTTPS 주소로 접속하세요. 실제 태블릿의 권한, 방향, 전면 카메라, 저장 동작을 수업 전에 확인하세요.

## 파일 구조

| 파일 | 내용 |
|---|---|
| `index.html`, `style.css` | 화면과 터치용 레이아웃 |
| `app.js` | 의상 데이터, 카메라, 합성, 저장, 초기화 |
| `start-photobooth.cmd` | PC에서 localhost로 여는 실행 파일 |
| `assets/costumes/*.png` | 얼굴 자리만 비어 있고 손·발이 있는 전신 캐릭터 그림 8개 |
| `assets/flags/*.png` | 카드용 국기 그림 |
| `dist/` | HTTPS 호스팅에 올릴 정적 파일 복사본 |

## 의상 그림 교체와 추가

1. 새 의상 PNG를 투명 배경 정사각형으로 준비합니다. 현재 그림은 1254×1254 픽셀이고, 손·발을 포함한 전신 캐릭터입니다. 얼굴 자리만 투명한 타원으로 비웁니다.
2. `assets/costumes/`에 넣고 `app.js`의 `COSTUMES` 배열에서 해당 `image` 경로를 바꾸거나 항목을 추가합니다. 배포용 `dist/assets/costumes/`에도 같은 파일을 복사합니다.
3. 각 항목의 `faceX`, `faceY`, `faceSize`, `faceHeight`는 0~1 비율입니다. 투명한 얼굴 자리의 중심과 대략적인 범위를 정합니다. 앱은 PNG의 실제 투명 영역을 따라 얼굴 마스크를 만듭니다. `faceShape`는 예비 타원 형태, `alignX`·`alignY`는 추가 위치 보정, `enabled`는 카드 표시 여부입니다.
4. 얼굴 사진은 마스크 안에서만 움직이고 확대됩니다. 새 그림의 투명한 얼굴 자리와 좌표가 어긋나면 데이터 값을 조정한 뒤 태블릿에서 다시 촬영해 확인합니다. 촬영 사진 안에 들어온 배경은 함께 보이므로 얼굴을 가이드에 가득 맞춰 찍어 주세요.

성별에 따른 선택 제한은 없습니다. 한복 두 종류도 각각 독립된 의상 항목입니다. 새 나라를 추가할 때는 국기 PNG를 `assets/flags/`에 넣고 `flagImage`를 지정합니다. 카드가 8개를 넘으면 페이지로 나뉘며 좁은 화면에서는 한 페이지에 4개를 보여줍니다.

## 확인할 항목

- 전면 카메라 권한 승인 및 실시간 영상
- 얼굴 가이드 안에 맞춘 촬영과 좌우 방향
- 8개 의상 각각에서 얼굴 위치와 크기
- 방향·크기 버튼과 손가락 드래그
- 다른 옷 입기 시 촬영 사진 유지
- PNG 저장 및 다음 친구 차례 시 이전 사진 삭제
- 1280×800, 1024×768 가로 화면의 버튼 크기와 스크롤

캐릭터 일러스트 8장은 이 프로젝트를 위해 이미지 생성 도구로 만들었습니다. 공통 제작 지시: “기존 의상 디자인을 유지하며 손·발·머리카락이 연결된 정면 전신 캐릭터로 만들기, 얼굴 타원만 실제 투명하게 비우기, 배경·글자 없이 유아에게 친근한 그림체.” 각 의상 특징은 `COSTUMES` 목록과 일치합니다. 국기 이미지는 [FlagCDN](https://flagcdn.com/)에서 가져왔습니다.
